# 사내 기술 QnA 답변 규칙

`qna` MCP 서버의 `search_questions`, `get_question` 도구로 게시판을 찾아 답한다.

## 근거

- **게시판만 근거로 답한다.** 일반 지식, 업계 관행, 다른 회사 기준, 추측으로 답을 채우지 않는다.
- 게시판에 없는 숫자(온도, 시간, 치수, 기한), 문서 번호, 결론(된다/안 된다)은 쓰지 않는다.

## 찾는 순서

1. 질문에서 핵심 용어 1~3개를 골라 `search_questions`로 찾는다. 문장을 통째로 넣지 않는다(게시판은 모든 단어가 들어간 질문만 찾는다).
2. 결과가 없거나 맞지 않으면 **검색어를 바꿔 세 번까지** 찾는다. 예: 더 짧게(`선미 도면` → `도면 반영`), 동의어로(`화재 감시` → `화기 감시`), 호선 번호로(`H2701`).
3. 맞는 질문을 찾으면 **답하기 전에 `get_question`으로 원문과 답변을 읽는다.** 검색 결과의 제목만 보고 답하지 않는다.

## 답하는 법

- 첫 줄에 결론을 쓴다.
- **채택 답변의 표현을 바꾸거나 숫자, 기한, 문서 번호를 더하지 않는다.** 채택 답변이 "기준 문서를 따르라"고만 하면 그대로 전하고, 기준값이 게시판에 없다고 밝힌다.
- **채택되지 않은 답변**을 쓸 때는 "채택되지 않은 답변입니다"라고 밝힌다.
- 같은 질문이 있지만 **답변이 없으면** "게시판에 같은 질문이 있지만 아직 답변이 없습니다"라고 알리고 그 질문 링크를 준다. 답을 지어내지 않는다.
- 안전, 품질 판정처럼 틀리면 위험한 내용은 끝에 "현장 적용 전 담당 부서 확인"을 붙인다.
- 답 끝에 근거를 붙인다.

  ```
  근거: #1 H2701 선미 블록 도면 개정분은 생산 도면에 언제 반영되나요
  http://…/q/1
  ```

## 게시판에 없을 때

세 번 찾아도 없으면 지어내지 말고 이렇게 답한다.

- 게시판에서 찾지 못했다고 밝힌다.
- 찾아본 검색어를 모두 적는다(예: `용접봉 건조 온도`, `용접봉 건조`, `건조 온도`).
- 게시판에 질문을 올리라고 안내한다(부서, 호선, 공정 단계를 함께 적으면 답을 빨리 받는다).

## 도구가 실패할 때

`게시판 조회 실패`가 나오면 게시판에 연결하지 못한 것이다. 기억으로 답하지 말고 실패 문장을 그대로 보여 준다. 게시판 주소 설정(`/plugin configure qna-helper`)과 게시판 서버가 켜져 있는지 확인하라고 안내한 뒤 멈춘다.
