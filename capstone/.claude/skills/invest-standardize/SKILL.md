# 투자신청서 표준양식 변환 (양식만, 내용 그대로)

표준양식의 칸 구성·작성 기준과 유형별 필수 항목은 이 문서 아래 **「업무 규칙」** 에 있다. 매핑할 칸은 그 칸 구성을 따른다.

## 원칙 — 내용은 절대 바꾸지 않는다
- 매핑 값은 **원본 글자를 그대로 복사**한다. 다듬기·요약·맞춤법 수정·단위 환산(억원→백만원)·합계 계산·번호 붙이기 금지.
- 원본에 **없는 칸은 빈 문자열("")** 로 둔다. 추정해서 채우지 않는다 (예: 견적 수를 세어서 넣지 않는다, 유형을 짐작해 넣지 않는다). 빈 칸은 점검 단계에서 '보완'으로 잡힌다 — 그게 맞는 동작이다.
- 원본의 글은 하나도 버리지 않는다. 칸에 맞지 않는 내용은 `기타원문` 에 그대로 넣는다 → '원문 (양식 외 내용)' 슬라이드.
- 원본에서 칸 이름 역할만 하던 글(예: `1. 투자 건명:`, 슬라이드 제목 `투자 효과`, 표 머리글 `공급사`)은 `라벨` 에 넣는다. 표준양식의 칸 이름이 그 자리를 대신한다.
- 이미지·도표처럼 글자로 옮길 수 없는 슬라이드는 `원본슬라이드첨부` 에 슬라이드 번호를 넣어 원본 그대로 붙인다.
- `inbox/` 원본은 읽기만 한다. 변환본과 기록은 스크립트가 `out/표준화/` 에 만든다.

## 절차
1. 표준양식인지 확인 — 표준양식이면 변환하지 않는다.
   ```bash
   python scripts/standardize.py detect inbox/*.pptx
   ```
2. 다른 양식이면 원본 글자를 모두 본다 (줄마다 `슬라이드 / 위치 / 글`).
   ```bash
   python scripts/standardize.py dump inbox/<파일>.pptx
   ```
3. 매핑 JSON 을 쓴다 → `out/표준화/<원본 파일 이름(확장자 제외)>.매핑.json`
   (Write 도구가 없으면 `cat > 경로 <<'EOF' … EOF` 로 저장)
   ```json
   {
     "원본": "inbox/<파일>.pptx",
     "투자명": "", "투자효과": "",
     "상세": {"투자시작": "", "투자경과": "", "투자금액(백만원)": "", "투자유형": "", "현수량": "", "필요수량": "",
             "투자수량": "", "부 유형": "", "AREA": "", "계획 NO": "", "선정 업체": "", "견적 수": ""},
     "부가": {"견적서 비교": "", "내년도 부하·조업도": "", "현 장비 재원 소개": "", "생산성 향상 산출": ""},
     "추가": [],
     "라벨": [],
     "기타원문": [],
     "원본슬라이드첨부": []
   }
   ```
   | 표준양식 칸 | 원본에서 찾을 것 (표현이 달라도 같은 뜻이면 이 칸) |
   |---|---|
   | 투자명 | 건명, 투자 건명, 사업명 |
   | 투자시작 / 투자경과 | 착수 시기 / 소요 기간 (투자경과 = 투자 시작 후 걸리는 개월 수) |
   | 투자금액(백만원) | 투자 금액, 소요 예산 — **단위 포함 원문 그대로** (`640백만원`) |
   | 투자유형 / 부 유형 | 투자 구분, 투자 성격 — 원문에 적힌 대로 |
   | AREA | 설치 장소, 위치 |
   | 계획 NO | 경영계획 번호, 계획 반영 여부 |
   | 현수량 / 필요수량 / 투자수량 | 원문에 각각 적힌 숫자만 (없으면 빈 칸). 현 = 지금 있는 수, 필요 = 있어야 할 수, 투자 = 이번에 사는 수 |
   | 선정 업체 | 원문에서 선정·채택·낙찰로 **명시된** 업체 |
   | 견적 수 | 원문에 숫자로 적힌 경우만 |
   | 투자효과 | 왜 필요한지 서술 |
   | 부가 → 생산성 향상 산출 | JMH·인원·금액 효과, 산출식, 회수기간 |
   | 부가 → 내년도 부하·조업도 | 부하율·조업도 수치 |
   | 부가 → 현 장비 재원 소개 | 운용연수, 보유·노후·교체 수량, 교체 사유 |
   | 추가 → 견적서 비교 표 | 업체 비교 표. 첫 행은 표준 머리글 `업체 / 금액(백만원) / 설립연도 / 비고` 로 써도 된다 (원본 머리글은 `라벨` 에). 나머지 셀과 선정·채택 사유 문장은 원문 그대로 (`본문`) |

   한 줄이 '칸 이름 + 값'이면 칸 이름 부분은 `라벨`, 값 부분은 해당 칸에 넣는다.
   예: `7. 투자 금액: 640백만원` → 라벨 `7. 투자 금액:` / 상세 `투자금액(백만원)` = `640백만원`.
   여러 줄 값은 원본 줄을 `\n` 으로 이어 붙이되, 각 줄은 원문 그대로 (앞의 `- ` 같은 글머리 기호는 빼도 된다).

4. 변환 + 검증
   ```bash
   python scripts/standardize.py build out/표준화/<이름>.매핑.json
   ```
   스크립트가 자동으로 확인한다:
   - **추가**: 매핑 값의 모든 줄이 원본에 그대로 있는가 (지어낸 글 0건)
   - **누락**: 원본의 모든 줄이 값·라벨·기타원문 중 하나로 옮겨졌는가 (버린 글 0건)
   - **왕복**: 변환본을 점검기와 같은 방식으로 다시 읽었을 때 매핑 값이 그대로 나오는가
   `통과` 가 아니면 출력된 줄을 보고 매핑을 고쳐 다시 build 한다. 원문을 고쳐서 맞추지 않는다.
   3번 고쳐도 통과하지 못하면 멈추고, 남은 추가·누락 목록을 그대로 보고한다 (그 신청서는 점검 단계에서 'R-100 보완'으로 보류된다).

5. 결과: `out/표준화/<이름>.pptx` (변환본), `out/표준화/<이름>.json` (원본 경로·해시, 검증 결과).
   점검은 `python scripts/review.py check` (인자 없이) — 표준양식 원본과 검증 통과한 변환본을 자동으로 고른다.

## 보고
변환한 파일, 통과 여부, 비어 있는 칸(원본에 없던 정보), 기타원문으로 옮긴 내용, 단위 경고.

# 업무 규칙 (변환에 필요한 부분: §2 표준양식 칸 구성·작성 기준, §4 유형별 필수 항목, §7 입력 자료)

아래는 CLAUDE.md 「업무 규칙」과 **같은 문장**이다 (테스트가 일치를 확인). 이 규칙으로 판단한다. 규칙을 바꿀 때는 CLAUDE.md §8 순서대로 CLAUDE.md 를 먼저 고친다. 수치 기준 값은 `config/기준값.json`.


## 2. 투자신청서 표준양식 (칸 구성과 작성 기준)

슬라이드 1 = 메인 표 하나. 왼쪽 칸 이름 / 오른쪽 값.
- **투자명**: 투자 건명 한 줄
- **투자상세**: 아래 상세 표 (머리글 행 + 값 행, 3쌍)

  | 투자시작 | 투자경과 | 투자금액(백만원) | 투자유형 |
  |---|---|---|---|
  | **현수량** | **필요수량** | **투자수량** | **부 유형** |
  | **AREA** | **계획 NO** | **선정 업체** | **견적 수** |

- **투자효과**: 왜 필요한지, 투자하면 무엇이 좋아지는지 서술
- **투자 상세 부가**: 투자유형에 맞는 필수 항목을 `- 항목명` 머리줄 아래에 작성 (§4). 길면 슬라이드를 추가하고 **슬라이드 제목을 항목명과 똑같이** 쓴다.

칸 작성 기준
- 투자유형: 생산필수 / 노후교체 / 생산성 향상(자동화) 중 하나 (주 유형). 부 유형: 두 유형에 걸칠 때만
- 투자시작: 착수 시점 (예: 27.4月) / **투자경과: 투자 시작 후 걸리는 기간(개월 수)** (예: 5개월)
- **현수량 = 지금 가진 수, 필요수량 = 있어야 할 수, 투자수량 = 이번에 살 수**
- AREA: 설치·사용 위치 (경영계획과 다르면 계획 변경으로 표시됨)
- 계획 NO: 경영계획 목록의 번호, 계획에 없으면 "계획外"
- 선정 업체 / 견적 수: 선정한 업체명과 받은 견적 수 (2곳 이상)
- 견적서 비교: 업체마다 `업체: 금액백만원, 설립 YYYY년 (선정)` 형식 또는 표(업체 / 금액(백만원) / 설립연도 / 비고). 최저가가 아니면 `선정 사유:` 문장
- 현 장비 재원 소개: `운용연수: N년`, `보유 수량: N대, 노후 수량: N대, 교체 수량: N대`, 교체 사유
- 글자와 표는 텍스트로 입력 (이미지로 붙인 글자·표는 읽지 못함), 구버전 .ppt 는 .pptx 로

## 4. 투자유형별 필수 부가 항목 (R-203)

| 부가 항목 | 작성 내용 | 생산필수 | 노후교체 | 생산성 향상(자동화) | 연결 규칙 |
|---|---|---|---|---|---|
| 견적서 비교 | 2곳 이상, 업체별 금액·설립연도, 선정 표시, 선정 사유 (업력 5년 미만 신생 업체는 최저가여도 미선정) | 필수 | 필수 | 필수 | R-104~R-107 |
| 내년도 부하·조업도 | 현재와 설치 후 부하·조업도 수치 (숫자) | 필수 | | | R-302 |
| 현 장비 재원 소개 | 운용연수, 보유 수량, 노후 수량, 교체 수량, 교체 사유 | | 필수 | | R-311~R-314 |
| 생산성 향상 산출 | 금액 · JMH · 인력 감소 3가지 모두 + 산출 근거 (공정 단축은 선택) | | | 필수 | R-321~R-322 |

## 7. 입력 자료

| 자료 | 형식 | 읽기 위한 조건 |
|---|---|---|
| 투자신청서 | pptx, 표준양식 (다른 양식은 표준양식으로 변환 후 점검 — R-100) | 글자는 텍스트 상자나 표로. 이미지 속 글자는 읽지 않음 |
| 견적서 | 부가 항목 '견적서 비교' | 업체별 금액·설립연도·선정 표시를 텍스트로 (원본 이미지는 참고용) |
| 경영계획 | `data/경영계획.xlsx` | 열: 계획 NO, 투자명, 투자유형, 장비 종류, 위치(AREA), 수량, 계획금액(백만원) |
| 집행 이력 | `data/집행이력.xlsx` | 열: 계획 NO, 신청일, 투자명, 집행금액(백만원) — M-7 분할 신청 판단 (관리 여부 [확인 필요]) |
| 과거 검토 사례 | 신청서 + 실제 판정 | 3~5건, 판정과 사유를 함께 기록해 정답셋으로 |

교육·시연 환경에는 업체명·금액·인명을 바꾼 **익명화 샘플만** 쓴다.
